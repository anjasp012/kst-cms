# RII Interactive Room - Admin CMS (ReactJS)

Folder ini disiapkan untuk antarmuka **Admin CMS (ReactJS)** yang akan mengelola:
- 👥 Master Data 8 Kelompok Pengguna (Persona / Modul Pengguna)
- 🌐 Master Data 9 Zona Riset BRIN (Token Tantangan)
- 🏢 Master Data Pusat Riset & Organisasi Riset BRIN
- 💡 Katalog Inovasi & Riset (TRL 1-9, Ringkasan, Dampak, Media, dan Bobot Persona)
- 📬 Review & Manajemen Usulan Topik Riset / Feedback Pengunjung
- 📊 Dashboard Analitik Interaksi Meja Pameran

## Integrasi Backend API
- Backend API Base URL: `http://localhost:8000/api/v1`
- Swagger Documentation: `http://localhost:8000/docs`
- Auth Endpoint: `POST /api/v1/auth/login-json`
